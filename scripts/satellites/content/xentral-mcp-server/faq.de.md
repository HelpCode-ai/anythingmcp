### Gibt es einen MCP-Server für Xentral?
Ja, diesen hier. Er verbindet die aktuelle Xentral-API über AnythingMCP mit Claude, ChatGPT und Copilot: 30 Tools für Artikel, Bestände pro Lager und Lagerplatz, Kunden, Lieferanten, Aufträge, Lieferscheine mit Sendungsverfolgung, Rechnungen mit Zahlungsstatus, Gutschriften, Bestellungen und Verbindlichkeiten.

### Was brauche ich für die Verbindung?
Die URL deiner Xentral-Instanz (https://<deine-id>.xentral.biz) und einen Personal Access Token, den ein Admin unter Administration → Kontoeinstellungen → Developer Einstellungen → Personal Access Token anlegt.

### Kann die KI Daten in Xentral ändern?
Nur Aufträge als Entwurf vorbereiten, die ein Mensch in Xentral freigibt. Alle anderen Tools lesen nur, und die Rechte des Tokens setzen die Grenze.

### Ist das mit einer echten Xentral-Instanz getestet?
Noch nicht. Der Adapter folgt der veröffentlichten API-Referenz von Xentral; Rückmeldungen aus dem Echtbetrieb sind willkommen.
