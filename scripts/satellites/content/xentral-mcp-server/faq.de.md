### Gibt es einen MCP-Server für Xentral?
Ja, diesen hier. Er verbindet die REST-API von Xentral über AnythingMCP mit Claude, ChatGPT und Copilot: 7 Tools für Artikel, Kunden, Aufträge, Rechnungen und Lagerbestände.

### Was brauche ich für die Verbindung?
Die URL deiner Xentral-Instanz und einen API-Benutzer (Einstellungen → Benutzer → API); Login und Passwort nutzt der Connector für die Basic-Authentifizierung.

### Kann die KI Daten in Xentral ändern?
Nein. Alle sieben Tools lesen nur.

### Ist das mit einer echten Xentral-Instanz getestet?
Noch nicht. Der Adapter folgt der API-Dokumentation von Xentral; Rückmeldungen aus dem Echtbetrieb sind willkommen.
