## NocoDB with AI Agents

NocoDB is an open-source Airtable alternative that turns relational databases into smart spreadsheets. By connecting its v3 REST API to AnythingMCP, AI agents can discover workspaces, bases, and tables, inspect column schemas, view configurations, query and filter records, and create, update, or delete rows.

## Quick Setup

```bash
git clone https://github.com/HelpCode-ai/anythingmcp.git
cd anythingmcp && docker compose up -d
```

Open `http://localhost:3000/connectors/store`, import the NocoDB adapter, and configure:
- `NOCODB_URL`: Your NocoDB host (e.g., `https://app.nocodb.com` or `https://nocodb.example.com`).
- `NOCODB_API_TOKEN`: Your API token created under **Team & Settings > API Tokens**.

```json
{
  "mcpServers": {
    "nocodb": { "url": "http://localhost:4000/mcp" }
  }
}
```

## Available Tools

| Tool | Description |
|------|-------------|
| `nocodb_list_workspaces` | List all workspaces visible to the API token (`w_...` IDs) |
| `nocodb_list_bases` | List bases within a workspace (`p_...` IDs) |
| `nocodb_list_tables` | List tables within a base (`m_...` IDs) |
| `nocodb_get_table` | Get table schema and field definitions |
| `nocodb_list_views` | List views (Grid, Kanban, Gallery, Form) in a table |
| `nocodb_list_records` | Query and paginate records with `where`, `sort`, and `fields` |
| `nocodb_get_record` | Retrieve a single record by numeric row ID |
| `nocodb_count_records` | Count records matching an optional filter condition |
| `nocodb_create_record` | Insert a new record into a table with custom field values |
| `nocodb_update_record` | Update existing record fields by numeric row ID |
| `nocodb_delete_record` | Delete a record from a table by numeric row ID |
