## ImmobilienScout24 mit KI-Agenten

ImmobilienScout24 ist Deutschlands größtes Immobilienportal. Die Verbindung der API mit MCP ermöglicht KI-Agenten die Immobiliensuche und detaillierte Objektinformationen.

## Schnelleinrichtung

```bash
git clone https://github.com/HelpCode-ai/anythingmcp.git
cd anythingmcp && docker compose up -d
```

Öffnen Sie `http://localhost:3000/connectors/store`, importieren Sie den ImmobilienScout24-Adapter und geben Sie Ihren ImmobilienScout24 **Consumer Key** und **Consumer Secret** ein: das API-Schlüsselpaar aus dem [Self-Service-Portal](https://selfservice.immobilienscout24.de) (Business-Konto erforderlich), nicht die E-Mail-Adresse und das Passwort Ihres Logins. Für die Such-API ist zusätzlich eine [Content-Partner-Freigabe](https://api.immobilienscout24.de/more/api-permission-request/) nötig.

```json
{
  "mcpServers": {
    "is24": { "url": "http://localhost:4000/mcp" }
  }
}
```
