## Schritt 1 — AnythingMCP starten

Ist Ihr ERP aus dem Internet erreichbar, nutzen Sie die [AnythingMCP Cloud](https://cloud.anythingmcp.com). Läuft es in Ihrem eigenen Netzwerk (SAP Business One auf einem lokalen Server, JTL-Wawi, Sage 100, Dynamics NAV), betreiben Sie AnythingMCP self-hosted direkt daneben:

```bash
mkdir anythingmcp && cd anythingmcp
curl -fsSLo docker-compose.yml \
  https://raw.githubusercontent.com/HelpCode-ai/anythingmcp/main/docker-compose.quickstart.yml
printf 'JWT_SECRET=%s\nENCRYPTION_KEY=%s\n' "$(openssl rand -hex 32)" "$(openssl rand -hex 32)" > .env
docker compose up -d   # → http://localhost:3000
```

Einen internen Hostnamen tragen Sie in `SSRF_ALLOWED_HOSTS` ein; private Adressen lehnt AnythingMCP standardmäßig ab.

## Schritt 2 — Den Connector für Ihr ERP installieren

Klicken Sie in der Tabelle oben auf **Installieren** (Cloud) oder öffnen Sie in Ihrer eigenen Instanz **Connectors → Store** und wählen Sie Ihr ERP. Tragen Sie die API-Zugangsdaten ein, die in der Einrichtungsanleitung aufgeführt sind. Beim Import macht AnythingMCP einen Testaufruf und zeigt Ihnen, ob die Zugangsdaten funktionieren.

Legen Sie die Zugangsdaten mit einem ERP-Benutzer an, der nur das sieht, was auch die KI sehen soll. Die KI erbt genau diese Rechte, nicht mehr.

## Schritt 3 — Festlegen, was die KI darf

Die meisten ERP-Adapter lesen nur. Adapter mit Schreibzugriff kennzeichnen die entsprechenden Tools als schreibend: SAP Business One kann Kundenaufträge anlegen, Odoo und ERPNext können Datensätze anlegen und ändern, Dynamics NAV kann OData-Pages aktualisieren. Beginnen Sie mit einem MCP-Server, dessen Rolle nur die lesenden Tools freigibt, und schalten Sie schreibende Tools später einzeln dazu.

## Schritt 4 — Claude, ChatGPT oder Copilot verbinden

- **Claude:** *Customize → Connectors → Add custom connector*, dann die URL des MCP-Servers einfügen. Schritt für Schritt: [So fügen Sie Claude einen eigenen Connector hinzu](https://anythingmcp.com/guides/how-to-add-a-custom-connector-to-claude).
- **ChatGPT:** Dieselbe öffentliche HTTPS-URL in den ChatGPT-Einstellungen als Connector (App) hinzufügen.
- **Claude Code, Cursor, VS Code / Copilot:** Die URL mit einem `X-API-Key`-Header eintragen.

## Ihr ERP ist nicht dabei?

Bei individuellen, älteren oder On-Premises-ERPs ist das der Normalfall, und genau dafür wurde AnythingMCP bei [KOCH Freiburg](https://www.kochfreiburg.de/) entwickelt. Dort verbindet es ein On-Premises-ERP, ein CRM, SOAP-Services und Datenbanken mit KI-Assistenten:

- **Das ERP hat eine REST- oder OData-API:** Importieren Sie die OpenAPI-Spezifikation, und jeder Endpunkt wird zum Tool. Siehe [OpenAPI to MCP](https://anythingmcp.com/guides/openapi-to-mcp).
- **Es bietet SOAP-Webservices an** (häufig bei älteren .NET- und Java-ERPs): Importieren Sie die WSDL. Siehe [SOAP to MCP](https://anythingmcp.com/de/guides/soap-to-mcp).
- **Erreichbar ist nur die Datenbank:** Verbinden Sie SQL Server, Oracle, PostgreSQL oder MySQL mit einem Datenbankbenutzer, der nur lesen darf. Siehe [Datenbank to MCP](https://anythingmcp.com/de/guides/database-to-mcp) und [SQL Server mit Claude verbinden](https://anythingmcp.com/de/guides/connect-mssql-to-claude).

## Sicherheit und Governance

- **Zuerst nur lesen:** Rollen legen fest, welche Tools ein MCP-Server anbietet; alle anderen sehen die Clients gar nicht.
- **Minimale Rechte an der Quelle:** Der ERP-Benutzer hinter den Zugangsdaten begrenzt, worauf ein Tool überhaupt zugreifen kann.
- **Response-Mapping** entfernt Felder wie Bankverbindungen oder Gehälter, bevor sie das Modell erreichen.
- **Audit-Log:** Jeder Aufruf mit Eingabe, Ausgabe, Dauer und Status, bei Self-Hosting in Ihrer eigenen Datenbank.
- **SSO und SCIM** (Entra ID, Okta, Google, Auth0) sind in der Self-hosted-Version enthalten.

## FAQ

**Wie verbinde ich mein ERP mit Claude?**
Installieren Sie den Adapter Ihres ERP in AnythingMCP, tragen Sie die API-Zugangsdaten ein und fügen Sie die URL Ihres MCP-Servers in Claude als Custom Connector hinzu. Gibt es keinen Adapter, binden Sie die REST-API, die SOAP-Services oder die Datenbank des ERP direkt an.

**Kann auch ChatGPT meine ERP-Daten lesen?**
Ja. Derselbe MCP-Server funktioniert in ChatGPT als Connector. ChatGPT verbindet sich aus dem Internet, die URL muss also öffentlich per HTTPS erreichbar sein, zum Beispiel in der AnythingMCP Cloud.

**Kann die KI Daten in meinem ERP ändern?**
Nur über schreibende Tools, und nur, wenn Sie einer Rolle Zugriff darauf geben. Die meisten ERP-Adapter lesen nur.

**Verlassen meine ERP-Daten mein Netzwerk?**
Bei Self-Hosting bleiben Zugangsdaten und Audit-Log auf Ihrem Server. Zum KI-Modell, das Sie nutzen, gelangen nur die Felder, die ein Tool zurückgibt, und per Response-Mapping entfernen Sie Felder, bevor es so weit ist.

**Was kostet das?**
Self-Hosting ist kostenlos und Open Source (AGPL-3.0, einschließlich kommerzieller Nutzung im eigenen Unternehmen). Die AnythingMCP Cloud beginnt mit einer kostenlosen 7-Tage-Testphase.

**Was, wenn wir Hilfe bei einem ERP brauchen, das nicht in der Liste steht?**
Stellen Sie auf GitHub eine [Adapter-Anfrage](https://github.com/HelpCode-ai/anythingmcp/issues/new?template=adapter_request.yml) oder wenden Sie sich an [helpcode.ai](https://helpcode.ai), das Team hinter AnythingMCP.
