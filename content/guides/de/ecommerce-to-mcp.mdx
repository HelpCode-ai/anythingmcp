## Schritt 1 — AnythingMCP starten

Shop- und Marktplatz-APIs sind aus dem Internet erreichbar, daher ist die [AnythingMCP Cloud](https://cloud.anythingmcp.com) der schnellste Einstieg. Wenn die Zugangsdaten im Haus bleiben sollen, betreiben Sie AnythingMCP self-hosted:

```bash
mkdir anythingmcp && cd anythingmcp
curl -fsSLo docker-compose.yml \
  https://raw.githubusercontent.com/HelpCode-ai/anythingmcp/main/docker-compose.quickstart.yml
printf 'JWT_SECRET=%s\nENCRYPTION_KEY=%s\n' "$(openssl rand -hex 32)" "$(openssl rand -hex 32)" > .env
docker compose up -d   # → http://localhost:3000
```

## Schritt 2 — Einen Connector pro Vertriebskanal installieren

Klicken Sie in der Tabelle auf **Installieren** (Cloud) oder öffnen Sie **Connectors → Store**. Bei Marktplätzen mit OAuth (Amazon, eBay, Etsy, OTTO, Zalando, Mercado Libre) werden Sie zur Autorisierung an den Anbieter weitergeleitet; die übrigen fragen nach einem API-Key oder nach Benutzer und Passwort. Legen Sie alle Kanäle auf denselben MCP-Server, dann kann die KI sie in einer einzigen Antwort vergleichen.

## Schritt 3 — Schreibzugriffe hinter einer Rolle halten

Die meisten Marktplatz-Adapter lesen nur. Die Shopsysteme können auch Daten ändern: WooCommerce, Magento, BigCommerce und Ecwid können Produkte und Bestellungen anlegen oder ändern, OTTO Market kann Bestände und Preise aktualisieren, eBay den Preis eines Angebots. Geben Sie der KI zunächst eine Rolle mit reinem Lesezugriff und schalten Sie schreibende Tools bewusst dazu.

## Schritt 4 — Claude, ChatGPT oder Copilot verbinden

- **Claude:** *Customize → Connectors → Add custom connector*, dann die URL des MCP-Servers einfügen ([Schritt für Schritt](https://anythingmcp.com/guides/how-to-add-a-custom-connector-to-claude)).
- **ChatGPT:** Die öffentliche HTTPS-URL in den ChatGPT-Einstellungen als Connector (App) hinzufügen.
- **Claude Code, Cursor, VS Code / Copilot:** Die URL mit einem `X-API-Key`-Header eintragen.

## Sicherheit und Governance

- **Rollen bestimmen die Tools:** Ein MCP-Server bietet nur die Tools an, die seine Rolle freigibt.
- **Response-Mapping** entfernt Kundenadressen, Telefonnummern oder Zahlungsdaten, bevor sie das Modell erreichen.
- **Audit-Log:** Jeder Aufruf mit Eingabe, Ausgabe, Dauer und Status.
- **Zugangsdaten** werden mit AES-256-GCM verschlüsselt; OAuth-Tokens werden automatisch erneuert.

## FAQ

**Wie verbinde ich meinen Onlineshop mit Claude?**
Installieren Sie den Adapter Ihres Shops in AnythingMCP, autorisieren Sie ihn und fügen Sie die URL Ihres MCP-Servers in Claude als Custom Connector hinzu.

**Kann ich mehrere Marktplätze gleichzeitig abfragen?**
Ja. Legen Sie alle Kanal-Connectoren auf einen MCP-Server; die KI ruft jeden einzeln auf und führt die Antworten zusammen.

**Funktioniert das auch mit ChatGPT?**
Ja, als Connector mit der öffentlichen HTTPS-URL Ihres MCP-Servers, zum Beispiel in der AnythingMCP Cloud.

**Kann die KI Preise, Bestände oder Bestellungen ändern?**
Nur über schreibende Tools, und nur, wenn eine Rolle ihr Zugriff darauf gibt. Die meisten Marktplatz-Adapter lesen nur.

**Mein Shopsystem steht nicht in der Liste. Kann ich es trotzdem anbinden?**
Wenn es eine REST-API mit OpenAPI-Spezifikation hat, importieren Sie die Spezifikation ([OpenAPI to MCP](https://anythingmcp.com/guides/openapi-to-mcp)); GraphQL-APIs funktionieren genauso ([GraphQL to MCP](https://anythingmcp.com/de/guides/graphql-to-mcp)).

**Gelangen Kundendaten zum KI-Anbieter?**
Nur die Felder, die ein Tool zurückgibt, und per Response-Mapping entfernen Sie personenbezogene Daten, bevor sie Ihre AnythingMCP-Instanz verlassen.
