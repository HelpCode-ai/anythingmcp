AnythingMCP · CLI

amcp
from the terminal.

Call MCP tools, run code-mode programs and manage your whole instance — by hand, in scripts or from an agent.

$npm i -g @anythingmcp/cli

zsh — ~/work
$ amcp login --browser --url https://cloud.anythingmcp.com
